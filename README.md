# RepDex

RepDex is a workout tracking app designed to make strength training simple, structured, and progressive.

The app helps users create workout plans, follow their training routine, track performed sets and repetitions, and review their workout history. RepDex is built around the idea that training should be easy to follow while still supporting progressive overload.

## What RepDex does

RepDex allows users to create custom workout plans or choose from predefined training templates such as Push Pull Legs, Upper Lower, Full Body, Torso/Limbs, Bro Split, and other common splits.

Each workout plan can define training days, rest days, exercises, target repetition ranges, planned sets, rest times, and starting weights.

During a workout, RepDex guides the user through each exercise and set. After every set, the app asks how many repetitions were completed and starts a rest timer. When the rest time is over, RepDex notifies the user with a sound so they know when to start the next set.

RepDex supports progressive overload by checking whether the user reached the upper end of the target repetition range. If the user performs well enough, the app asks which weight should be used next time and automatically saves it for the next workout.

The home screen shows the current training day, the next planned workout, and a body map highlighting the muscles trained today. After completing a workout, the trained muscles are shown in red to indicate that they have already been trained.

RepDex also includes a workout history where completed sessions are stored. Users can review which exercises they performed, how many sets and repetitions they completed, and which weights they used.

## Main features

- Custom workout plans
- Predefined workout templates
- Training day and rest day planning
- Exercise tracking with sets, repetitions, and weight
- Target repetition ranges
- Rest timer with optional sound
- Progressive overload support
- Automatic next-weight suggestions
- Workout history
- Body map for trained muscles
- Local data storage without accounts or cloud sync

## Privacy

RepDex stores workout data locally on the device. The app does not require an account, does not upload workout data to a server, and does not use advertising or tracking.
