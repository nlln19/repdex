# Contributing to RepDex

Thank you for your interest in contributing to RepDex.

RepDex is a simple workout tracking app focused on workout planning, progressive overload, rest timers, body-map feedback and workout history.

## How to contribute

You can contribute by:

- reporting bugs
- suggesting new features
- improving the user interface
- improving documentation
- fixing issues in the code
- testing the app on different devices

## Reporting bugs

When reporting a bug, please include:

- what happened
- what you expected to happen
- steps to reproduce the issue
- screenshots or error logs if possible
- device and platform information

Example:

```text
Device: Android / Chrome / Windows
Issue: Rest timer does not play sound
Steps:
1. Start a workout
2. Finish one set
3. Wait until the timer ends
Expected: A sound should play
Actual: No sound plays
```

## Suggesting features

For feature requests, briefly explain:

- what the feature should do
- why it would be useful
- where it should appear in the app

Keep suggestions simple and focused.

## Code style

Please keep the code:

- readable
- simple
- consistent with the existing Flutter structure
- focused on one change at a time

Avoid large unrelated changes in a single pull request.

## Pull requests

Before opening a pull request:

1. Make sure the app runs.
2. Test the changed feature manually.
3. Keep the pull request description clear.
4. Mention what was changed and why.

Useful commands:

```powershell
flutter pub get
flutter run -d chrome
```

If needed:

```powershell
flutter clean
flutter pub get
flutter run -d chrome
```

## Privacy

RepDex stores workout data locally on the device. Contributions should respect this privacy-first approach unless a future feature clearly requires otherwise.
